# RISK-01 — synthetic risk and review notes

Original fixture authored for this repository; all observations are invented.

## RISK-01:P1 — incorrect drafts

Two of the 40 sampled requests produced a draft with an incorrect account-specific instruction. Reviewers rejected both drafts before sending. The exercise did not measure how often reviewers might miss such an error in routine use.

## RISK-01:P2 — sensitive information

Four sampled requests included sensitive employee details. The proposed pilot excludes those requests, but the source note does not specify a validated detection control or provider retention setting.

## RISK-01:P3 — review boundary

The proposed workflow requires a human to approve every outgoing response. This is a proposed control; no production approval log or enforcement result exists in this fixture.
